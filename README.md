#  E-Commerce Product Recommendation System

##  Project Overview

This project is a Machine Learning-based Product Recommendation System built using Python, MySQL, SQLAlchemy, Surprise SVD, and Streamlit.

It recommends products to customers based on their previous purchase history using the Singular Value Decomposition (SVD) collaborative filtering algorithm.

---

## Features

- Customer Selection
- Customer Details
- Purchased Products
- Product Recommendation using SVD
- Total Orders
- Total Spending
- Top Selling Products Analysis
- Revenue by Product Analysis
- Interactive Streamlit Dashboard

## Installation

Clone the repository

```bash
git clone <repository_link>
```

Install the required libraries

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
